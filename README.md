# groundwork

**AI-native delivery practices — template, reference, and auditor.**

A vendor-agnostic, tech-stack-flexible, modular collection of software-delivery
practices for teams building with AI coding agents: instruction architecture,
quality-gate enforcement ladders, generated-artifact freshness, docs-as-wiki
governance, layered review systems, and a built-in learning loop. Works as a
starting point for greenfield projects and as an audit tool that assesses a
brownfield repo and produces actionable, prioritized recommendations.
