# References that must not appear in repository content: the original
# repository's issue-tracker keys and its organization's name. One extended
# regular expression per line; `(?i)` makes a line case-insensitive. See
# check-no-tracker-refs.ts.
#
# Those values come from the scanned repository's `.config/jig.yaml`, so this
# file spells out neither: `{{team}}` stands for `issue_tracker.team` and
# `{{owner}}` for the owner part of `review.repo_slug`. Changing either field
# changes what the gate forbids, so a test pins both by digest. The gate does
# not scan the pattern file it reads, and a test checks that this one
# contains nothing its own patterns reject.
\b{{team}}-[0-9]+\b
# The same key folded into a name: `<team>1234-main`, `PRE_<TEAM>_1234_ACCOUNT`,
# `feature/<team>-42-fix`. A separator makes any number a key; without one,
# three digits are needed, so a word such as `<team>12` stays allowed.
(?i)(?<![a-z0-9]){{team}}([-_][0-9]+|[0-9]{3,})(?![0-9])
(?i){{owner}}
#
# Allowed: the text an allow pattern (`!`) matches, tested against
# `<relative path>:<line>`. Only the matched text is exempt, so a pattern
# covers the permitted occurrence itself, not the line it sits on.
#
# The repository's own address, as a whole URL: it starts at
# `https://` with nothing joined on before it, so a host such as
# `notgithub.com` stays rejected, and the name ends there (optionally as
# `.git`) with no further name character after it, so a sibling such as
# `jig-other` or `jig..private` stays rejected while a sentence
# may still end on the address.
!(?<![-+.\w])https://github\.com/{{owner}}/jig(\.git)?(?![-\w])(?!\.[-.\w])
# The publisher fields of the plugin and marketplace manifests.
!(?i)^(plugin/\.(claude|codex)-plugin/plugin|\.claude-plugin/marketplace)\.json:\s*"(author|owner|developerName)":\s*(\{\s*"name":\s*)?"{{owner}}"
# This repository's own values as a consumer of its skills: real account,
# team and repository names, which is what configuration is for.
!^\.config/jig\.yaml:.*
