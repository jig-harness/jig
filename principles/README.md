# Design principles

Seven principles govern everything in jig. Each has its own page with
rationale and concrete consequences:

| # | Principle | One-liner |
|---|-----------|-----------|
| 1 | [Principles over tools](01-principles-over-tools.md) | State the invariant; map tools per ecosystem; derive, don't declare |
| 2 | [Modular, profile-composed](02-modular-profile-composed.md) | Independent modules × maturity levels, composed by project profiles |
| 3 | [AI scaffolding as the spine](03-ai-scaffolding-as-the-spine.md) | Every practice is written to be operable by agents |
| 4 | [Enforcement-ladder discipline](04-enforcement-ladder.md) | Every rule names its rung and its promotion path |
| 5 | [Learning loop built in](05-learning-loop.md) | Misses become checks; instances backflow into the template |
| 6 | [Audit-first brownfield entry](06-audit-first.md) | "Where do I stand?" before "adopt module X" |
| 7 | [Accessible to newcomers](07-accessible-to-newcomers.md) | Plain language, glossary, no assumed familiarity |
