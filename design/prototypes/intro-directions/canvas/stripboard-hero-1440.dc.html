Jig

A work item goes in. A pull request you can merge, or a question for you, comes out.

Give an agent a work item; it builds the change, runs the checks and works through review until the pull request is ready or needs your decision. You merge.

The line

Seven stations, run as a loop.

Every change passes the same stations: pick up, build, open, drive, repair, merge, follow up. A person merges at the sixth. The follow-up sends what the merge owes back to the first.

The tick

A timer wakes the dispatcher.

Every few minutes the dispatcher reads the tracker, the pull requests and the running sessions. Then it starts what should be running and is not.
