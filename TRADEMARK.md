# The name and the logo

**Jig Harness**, its short form **Jig** as the name of this project, the
logo ([assets/brand/](assets/brand/)) and the domain jig-harness.dev are
trademarks of Van Code B.V., held apart from the code on purpose ([GOVERNANCE.md](GOVERNANCE.md#licence-copyright-and-name)): the
code is open under the Apache License 2.0, which grants no right to the
name ([LICENSE](LICENSE) § 6), and the name stays with the project whatever
happens to the company that holds the copyright. This page says what you
may do with the name without asking. The project's full name is Jig
Harness; the documents say Jig for short. The word jig on its own is a
common noun, and the project claims it only as that short form.

## You may, without asking

- Say that you use Jig, audit with Jig, or built something with Jig.
- Call a tool that implements one of Jig's extension contracts
  ([plugin/EXTENDING.md](plugin/EXTENDING.md)) "`<name>` for Jig" or
  `jig-<name>`, as long as its description says who maintains it.
- Link to the repository and the website, quote the documents, and show the
  logo when you refer to the project itself.
- Redistribute unmodified copies under the name, as the licence allows.

## You may not, without written permission

- Call a modified version, a fork or a derived product "Jig", or a name
  close enough to be confused with it, or use the logo for one. Rename it,
  and say that it derives from Jig.
- Use the name or the logo in a product, service, plugin, package,
  organization or domain name in a way that suggests the project endorses
  or maintains it.
- Register the name, the logo or a confusable variant as a trademark or a
  domain anywhere.

## Asking

Open an issue on this repository, or, if the question must stay private,
use the private report form
([GOVERNANCE.md § Reaching the maintainer](GOVERNANCE.md#reaching-the-maintainer)).
