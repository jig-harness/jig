# Releasing

After the merge, run `/release-notes` to write the notes. Without slash
commands, read [its procedure](../skills/release-notes/SKILL.md) and follow
it.

Plugin skills resolve through the installed plugin: `/tools:summarize-changes`
needs no fallback. Paths are not invocations: `skills/summarize-changes/`,
`/summarize-changes/SKILL.md` and `/summarize-changes.md`.
