# Releasing

After the merge, run `/release-notes` to write the notes. Without slash
commands, read [its procedure](../skills/release-notes/SKILL.md) and follow
it.

Plugin skills are left to the plugin's installation notes:
`/tools:summarize-changes` is not checked. Paths are not invocations:
`skills/summarize-changes/`, `/summarize-changes/SKILL.md` and
`/summarize-changes.md`.
