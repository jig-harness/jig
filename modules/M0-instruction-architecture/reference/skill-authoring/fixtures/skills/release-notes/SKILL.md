# Release notes

Collect the pull requests merged since the last tag, group them by change
type, and write one line per change for the people who install the release.

Read [references/style.md](references/style.md) before writing the first
line: it says how a line is worded.

## Not this skill

A single pull request's change note belongs to the changelog skill.
