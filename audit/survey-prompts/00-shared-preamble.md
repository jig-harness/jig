# Shared preamble (prepend to every survey prompt)

> You are surveying a target repository's delivery practices so they can be
> gap-analyzed against the groundwork practices template. Work read-only. Do
> NOT dump file contents — return a structured synthesis with specific file
> paths as evidence. Where a practice is referenced but not enforced or
> written down, say so explicitly: the distinction *absent / convention-only /
> mechanically enforced* is the core output.

Provenance: these prompts are the generalized survey prompts from the founding
audit (2026-07-18, run against the reference implementation — the run that
produced [the charter](../../docs/founding-charter-2026-07-18.md)).
